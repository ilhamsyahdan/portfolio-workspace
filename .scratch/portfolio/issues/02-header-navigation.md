# 02: Header Component with Hash Navigation

**What to build:** A fixed header component at the top of the page with personal logo/initials and navigation links to content sections (#projects, #blog, #about, #contact). Clicking a link smoothly scrolls to the corresponding section anchor. The active section is highlighted in the header as the user scrolls through the page. Works on mobile (hamburger menu) and desktop (horizontal nav).
